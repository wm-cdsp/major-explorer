# Visual assets

William & Mary assets downloaded from the university's public site on October 20, 2026:

- `wm-wordmark.svg`: https://www.wm.edu/images/wm_logo_horizontal_green_gold.svg (unaltered official artwork; links to the university homepage).
- `wm-pattern.jpg`: https://www.wm.edu/brand/_images/visual-brand/visual-brand-photo-card-link-graphic-elements.jpg (quatrefoil pattern, cropped proportionally in the opening panel).
- Palette: https://www.wm.edu/brand/visual-brand/color-palette/ — W&M Green #004E38, W&M Gold #B79257, accessible gold #846838, Griffin Green #28463D.
- Typography: https://www.wm.edu/brand/visual-brand/typography/ — approved free alternatives Aleo and Roboto, self-hosted Latin variable WOFF2 files from Google Fonts. Their SIL Open Font Licenses are included alongside the fonts.
- Usage: https://www.wm.edu/brand/visual-brand/logos/usage-guidelines/ and https://www.wm.edu/brand/visual-brand/graphic-elements/.

`explorer.svg` and the two button line icons are original interface graphics, not university marks.

## CDSP style reference (October 20, 2026)

- Reference: https://cdsp.wm.edu/ and its public `-css/homepage.css` and `-css/custom.css`.
- `cdsp-bridge.jpg`: https://cdsp.wm.edu/__homepage/assets/hero_background.jpg — original bridge and data-themed artwork, unaltered; CSS adds a dark overlay for legible labels.
- `wm-wordmark-white.svg`: exact university wordmark SVG from the CDSP homepage footer, unaltered, linked to wm.edu.
- CDSP colors: green #115740, Spirit Gold #F0B323, neutral text #282626.
- Self-hosted Roboto Mono Latin variable font from Google Fonts; its SIL Open Font License is included. Aleo remains the approved free alternative to the site's licensed Adelle serif, paired with Roboto body text.
- The earlier green/gold wordmark and quatrefoil remain archived assets; they are not used by the current interface.

## Current green values

Verified against https://www.wm.edu/brand/visual-brand/color-palette/ on October 20, 2026: the page canvas and primary accents use W&M Green #004E38 (RGB 0, 78, 56). The masthead and dark control states use the approved secondary Dark Green #183028. The CDSP reference palette documented above is historical source context.
